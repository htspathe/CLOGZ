# Motion V3 — sources textuelles uniquement

Ce dépôt contient le moteur de montage (JS/Python), config, aperçu HTML, scripts et SRT de l'archive `CLOGZ_Projet_Modifiable.zip`. Il **n'embarque pas** les plus de 100 Mo de médias, audio, fontes et MP4. Le code ne pourra pas rendre directement sans replacer les fichiers attendus dans `assets/` et régler FFmpeg/Node/Python selon `README.md`.

Pour récupérer les médias, utiliser l'archive de travail originale si le propriétaire la possède, ou récupérer les ressources publiques CLOGZ via le `SOURCES.md` fourni. Les fontes doivent être réinstallées depuis leurs sources sous licences respectives. Éviter tout redistribution de visuels tiers sans autorisation.
